# XSUI
X-ray scattering API and UI for SAXS/WAXS

This app is built with 
 
- FastAPI
- Plotly
- pyFAI
- Dash
- SQAlchemy

### Install and run.

You can install this package locally:

    pip install -e .

Then you can run the server by using the main module

    python -m XSUI
